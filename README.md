# Veredas

A light-green theme for [Omarchy](https://omarchy.org) — soft, calm, botanical.
*vereda*: the quiet path that runs between houses.

![Omarchy](https://img.shields.io/badge/Omarchy-Veredas-5A8645)

![Veredas theme preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/PedroAugustoOK/omarchy-veredas-theme
```
